# VOLPT AI

Локальная интеллектуальная система поддержки пользователей на базе больших языковых моделей.

## Используемые технологии

* Python 3.13
* FastAPI
* PostgreSQL 17
* SQLAlchemy
* PyQt6
* JWT Authentication
* Ollama
* Phi-3 Mini

## Функциональные возможности

* регистрация пользователей;
* авторизация пользователей;
* создание диалогов;
* сохранение истории сообщений;
* локальная генерация ответов нейросети;
* работа без подключения к облачным сервисам;
* графический интерфейс пользователя.

## Структура базы данных

* users
* user_settings
* sessions
* messages

## Архитектура

PyQt6 Client → FastAPI API → PostgreSQL → Ollama → Phi-3 Mini
